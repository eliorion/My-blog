What my dev setup looked like 3 months ago vs. today.
The diff is wild.

3 months ago:
→ VS Code with a mouse
→ Split terminal tabs everywhere
→ Touch-typing? Never thought about it
→ Notes? A mess of random files
→ Goals? Vague intentions

Today:
→ vim as primary editor
→ tmux for everything terminal-related
→ Relearning to type properly (still slow, no regrets)
→ Obsidian with daily/weekly/monthly/yearly notes
→ SMART goals at every time horizon

The context: I joined the KubeCraft Career Accelerator and realized I needed to go deep on Linux fundamentals before anything else.

The goal isn't to be a "vim person" or a "keyboard nerd."

The goal is to be dangerous in any environment — a fresh Linux server, a remote machine, a container shell — with just the basics available.

You don't get there by knowing tools exist.

You get there by building reflexes.

And reflexes take reps.
