Hugo + GitHub Pages = a blog live in under an hour.
No server. No monthly bill. No ops headache.

I wanted my own corner of the internet for a long time.
But running a persistent server never worked out for me — cost, maintenance, life getting in the way.

Then I found this stack:
→ Hugo generates static HTML at build time
→ GitHub Actions builds and deploys on every push
→ GitHub Pages serves it for free

Zero infrastructure to babysit.
Git is the CMS.
Markdown is the editor.

For a technical blog, it's hard to beat.

I just launched mine — sharing my homelab projects, security research, and DevOps experiments that have been sitting on my hard drive for way too long.
