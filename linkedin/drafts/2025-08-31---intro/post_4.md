I almost spun up a VPS just to write blog posts.
Glad I didn't.

My original plan: personal server, custom domain, full control over the stack.
Classic over-engineering before writing a single word.

What I actually needed: a place to write and ship.

The setup I landed on:
→ Hugo for static site generation
→ GitHub for version control and hosting
→ GitHub Actions for automated deploys
→ Markdown files as content — no database, no CMS bloat

Total infrastructure I manage: none.

Now I can focus on the actual content — homelab builds, security research, DevOps tooling — instead of babysitting a server at 2am.

Sometimes the boring solution is the right one.
